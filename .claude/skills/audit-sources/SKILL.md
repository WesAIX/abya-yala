# Сверка источников главы

**1. Описания изданий — автоматически.**

```bash
uv run tools/bibcheck.py --chapter chapters/<глава>.md --apply
uv run tools/bibliography.py
```

Полные совпадения с каталогами отмечаются сами. Расхождения, «не найдено» и
«вручную» досверит агент.

**2. Утверждения — агент `source-audit`** на главу. Если он недоступен в
сессии — агент общего назначения с заданием «прочитай
`.claude/agents/source-audit.md` и действуй строго по нему». Передай ему
вывод шага 1, чтобы он знал, какие описания досверять вручную.

**3. Показ.** Перескажи владельцу: сколько утверждений подтверждено, что
расходится (что в главе — что в источнике — где), какие описания изданий
неверны, что не удалось проверить и почему. Расхождения и «нет доступа» —
разные новости, не смешивай их.

**4. Правки — по подтверждению владельца.** Расхождения в тексте главы
исправляет `chapter-revise` с отчётом сверки в качестве списка замечаний;
после — повторная сверка только изменённых утверждений. Неверные описания
изданий правь сам в `sources/bibliography.json`.

**5. Проверки и коммит.** `uv run tools/validate.py`,
`uv run tools/bibliography.py --check`; один коммит: журнал сверки, отметки в
библиографии, правки. Сообщение — «сверка главы N: подтверждено X из Y,
исправлено …».
