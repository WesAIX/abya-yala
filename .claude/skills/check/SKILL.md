# Проверки

```bash
uv run ruff check . && uv run ruff format --check .
uv run tools/validate.py            # данные, сноски, термины, иллюстрации, статусы, журналы сверки
uv run tools/figures.py --check     # рисунки глав не устарели
uv run tools/bibliography.py --check
uv run tools/build_site.py          # сайт собирается
```

Ошибки чинятся сразу. Предупреждения валидатора о журнале сверки значат,
что предложение со сноской изменилось после сверки: его нужно пересверить
(`/audit-sources`), а не удалить запись.

`uv run tools/bibcheck.py --all` (нужна сеть, несколько минут) запускай
только по просьбе или при ревизии библиографии.

В ответе не пересказывай чистый вывод построчно: что найдено и что с этим
делать; если всё чисто — одной строкой.
