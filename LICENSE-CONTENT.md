# Лицензии на содержание

Код проекта распространяется по лицензии MIT (см. [LICENSE](LICENSE)). Этот
файл описывает всё остальное.

## Тексты — CC BY-SA 4.0

Главы (`chapters/`), глоссарий (`glossary.md`), README и прочие тексты на
естественном языке распространяются по лицензии
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/deed.ru).

Можно копировать, распространять и перерабатывать тексты для любых целей,
включая коммерческие, при двух условиях: указать авторство со ссылкой на
репозиторий и распространять производные тексты на тех же условиях. Эта
лицензия совместима с лицензией текстов Википедии.

## Данные — CC BY 4.0

Наборы данных (`data/`) и реестр источников (`sources/bibliography.json`)
распространяются по лицензии
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/deed.ru).

Достаточно указать авторство со ссылкой на репозиторий; производные данные
можно распространять на любых условиях. Это сделано намеренно, чтобы данные
было легко переиспользовать в других проектах.

Сами исторические факты и цифры не охраняются авторским правом; лицензия
относится к их подборке, структуре и описаниям. Указывая авторство, пожалуйста,
сохраняйте и поле `sources`: оно ведёт к исходным исследованиям, авторов
которых тоже стоит указывать.

## Сторонние материалы

- **Цитаты из источников** приводятся в объёме, допустимом для цитирования, и
  остаются под правами их авторов и издателей; лицензии проекта на них не
  распространяются.
- **Natural Earth** — подложка карт; общественное достояние
  (<https://www.naturalearthdata.com/about/terms-of-use/>).
- **d3** — загружается с CDN, лицензия ISC.
- **Шрифты Alegreya и Alegreya Sans** — загружаются с Google Fonts, лицензия
  SIL Open Font License 1.1.
- **Издания правительства США** (Ройс 1899, Хорнадей 1889 и др.) находятся в
  общественном достоянии.
- Лицензии оцифрованных наборов данных, если они будут использованы,
  указываются в поле `license` записи в `sources/bibliography.json` и в
  описании набора в `data/README.md`.
