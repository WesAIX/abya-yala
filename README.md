# Абья-Яла

Текстово-графический конспект по истории коренных народов обеих Америк — от
заселения через Берингию до наших дней. *Абья-Яла* — название обеих Америк на
языке гуна (Панама и Колумбия).

Это проект для самообразования, его пишет не историк. Поэтому он строже к
источникам, чем к стилю: каждое утверждение либо подкреплено ссылкой, либо
явно помечено как оценка или гипотеза.

**Сайт с визуализациями:** <https://wesaix.github.io/abya-yala/>

## О чём

Конспект построен вокруг причинно-следственных связей, а не перечня племён.
Охват — три культурные зоны: север (США и Канада), Мезоамерика, Южная Америка
с Карибами. Отдельно рассматривается переходная зона севера Мексики и
юго-запада США.

Опорные тезисы, которые главы раскрывают и проверяют по источникам:

1. Заселение через Берингию шло несколькими волнами.
2. Развитие было самостоятельным; связи между регионами шли через цепочки
   посредников.
3. Эпидемии XVI–XVII вв. — демографическая катастрофа, во многом
   предшествовавшая завоеванию.
4. «Классический индеец» равнин — послеконтактное явление.
5. Сила индейских народов держалась на противоречиях держав; 1763 и 1815 гг. —
   потеря этого рычага.
6. Завоевание шло через удар по централизованным государствам; дольше
   держались мобильные децентрализованные народы.
7. Синхронный финал 1875–1885 гг.: индустриальные государства и уничтожение
   экономической базы.
8. Ассимиляция и возвращение через правовой суверенитет.

Тезисы — рабочие. Где источники их уточняют или опровергают, это написано в
главах, а не спрятано.

## Как читать

- **[Главы](chapters/README.md)** читаются прямо на GitHub, по порядку: каждая
  опирается на вывод предыдущей. Пока у глав есть только планы с тезисами;
  текст пишется по одной главе за раз.
- **[Визуализации](https://wesaix.github.io/abya-yala/)** открываются на сайте.
  Главы ссылаются на них, но смотреть их можно и отдельно.
  - [Родословная культур и народов](https://wesaix.github.io/abya-yala/visuals/genealogy/) —
    граф ~130 культур, языковых общностей, народов и государств в стиле
    таймлайна дистрибутивов Linux.
- **[Глоссарий](glossary.md)** — чем народ отличается от племени, нации,
  конфедерации и вождества, и другие термины, которые здесь различаются.
- **[Библиография](sources/BIBLIOGRAPHY.md)** — все источники, на которые
  ссылаются тексты и данные.

## Принципы

- **Факты, оценки и гипотезы разделены.** Факт идёт со сноской, оценка — с
  именем автора, гипотеза — с явной пометкой. Даты, цифры и цитаты не
  додумываются: если что-то не удалось проверить, так и написано.
- **Источники.** Предпочтение — первичным и академическим (Smithsonian
  *Handbook of North American Indians*, Ройс, Хорнадей, Торнтон, Деневан,
  Хямяляйнен и др.); популярные издания — только как дополнение. У каждой
  цифры в данных — ссылка на источник.
- **Без ложной точности.** Даты до 1500 г. приблизительны и так и показаны.
  Этнические территории не рисуются чёткими полигонами: миграции — стрелками,
  зоны — размытыми областями.
- **Данные отдельно от отображения.** Всё, что показывают визуализации,
  лежит в [`data/`](data/README.md) в JSON или CSV со ссылками на источники.
  Визуализации только читают эти файлы.
- **Терминология.** Самоназвание и устоявшееся русское название при первом
  упоминании: «ленапе (делавары)».

## Устройство репозитория

```
chapters/        главы (Markdown)
glossary.md      глоссарий
sources/         bibliography.json — реестр источников; BIBLIOGRAPHY.md генерируется из него
data/            наборы данных и их схемы (data/schema/)
visuals/         визуализации: статический HTML, d3 с CDN, без сборки
tools/           Python-скрипты проверки данных
index.html       главная страница сайта
```

## Работа с репозиторием

Нужен [uv](https://docs.astral.sh/uv/).

```sh
uv sync                              # зависимости инструментов
uv run tools/validate.py             # схемы, ссылки, покрытие источниками
uv run tools/bibliography.py         # пересобрать sources/BIBLIOGRAPHY.md
uv run tools/figures.py              # перерисовать рисунки глав (chapters/img/)
uv run ruff check . && uv run ruff format --check .
uv run python -m http.server         # локальный просмотр: http://localhost:8000/
uv run --group basemap tools/basemap.py   # пересобрать подложку карт из Natural Earth
```

Визуализации загружают данные через `fetch`, поэтому открывать их двойным
кликом как файл не получится — нужен локальный сервер (последняя команда).

Сайт публикуется GitHub Actions при каждом push в `main`, но только если
проходят все проверки ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)).
