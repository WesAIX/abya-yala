# Данные

Всё, что показывают визуализации, лежит здесь. Визуализации только читают эти
файлы и ничего в них не вычисляют задним числом. Лицензия — CC BY 4.0
(см. [LICENSE-CONTENT.md](../LICENSE-CONTENT.md)).

Правила для всех наборов:

- **Каждая цифра — с источником.** В JSON это поле `sources`: список
  `{"ref": "<ключ>", "loc": "<страница, таблица, карта>", "note": "…"}`, где
  `ref` — ключ из [`sources/bibliography.json`](../sources/bibliography.json).
  В CSV — колонки `source` (ключ) и `source_loc`.
- **Точность даты указана явно**: `documented` (известна по документам),
  `approx` (приблизительна; все даты до 1500 г.), `conventional` (условная дата
  для графика).
- **Неопределённость не прячется.** Где оценки расходятся, хранится диапазон
  (`low` / `high`) и автор каждой оценки, а не «среднее».
- **Что проверить — в поле `todo`.** Пометки показываются читателю в
  подсказках визуализаций.
- **Схема обязательна.** Для каждого набора есть JSON Schema в `schema/`;
  `uv run tools/validate.py` проверяет схему, ссылочную целостность и
  выводит покрытие источниками.

## Наборы

### `genealogy.json` — родословная культур и народов

Схема: [`schema/genealogy.schema.json`](schema/genealogy.schema.json).
Визуализация: [`visuals/genealogy/`](../visuals/genealogy/).

| Поле | Смысл |
|---|---|
| `lanes` | регионы — горизонтальные полосы графа |
| `nodes[].type` | `culture` — археологическая культура, `language` — языковая общность (реконструкция), `people` — народ, `polity` — государство или союз |
| `nodes[].start`, `end` | `{year, dating}`; год отрицательный до н. э.; `end: null` — существует сегодня |
| `nodes[].fate` | `extant` — существует, `ended` — перешло в потомков или слилось, `destroyed` — уничтожено или распалось |
| `nodes[].parents` | `{id, certainty}`; `certainty`: `established` — принятая связь, `probable` — вероятная или спорная, `hypothesis` — гипотеза |
| `nodes[].events` | события на линии узла |
| `links` | связи помимо родительских: `merge` — слияние, вхождение; `influence` — культурное влияние |
| `milestones` | общие вехи через весь граф |

Происхождение: данные перенесены из исходного `americas-peoples-graph.html`
без изменения содержания. Поля `dating` и `certainty` при переносе выставлены
автоматически (см. `meta.notes`). Источники пока не проставлены: покрытие
растёт по мере работы над главами, текущее значение показывает
`tools/validate.py`.
