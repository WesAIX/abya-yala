# Конспекты источников

Один файл на источник: `<ключ>.md`, где ключ — из
[`bibliography.json`](../bibliography.json). Здесь записывается то, что нужно
главам и данным: ключевые утверждения со страницами, цифры с указанием, как
автор их получил, спорные места и что пишут критики.

Шаблон:

```markdown
# <ключ> — Автор, «Название», год

Издание, по которому сделан конспект: …

## Главные утверждения
- … (с. N)

## Цифры
| Что | Значение | Как получено | Страница |
|---|---|---|---|

## Спорное и критика
- …
```

Когда выходные данные записи сверены с самим изданием, в `bibliography.json`
ставится `"checked": true`.
